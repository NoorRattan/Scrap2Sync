# Content and interaction guide

Scrap2Sync produces an editable draft from supplied facts. Its interface says
organize, draft and review. It makes no claim of perfection, uniqueness, universal
language support, learned team style or guaranteed response time.

## Profiles and copying

Concise bullets uses direct brief bullets with a preferred five items per section.
Standard update uses neutral professional bullets with eight preferred items.
Async detail uses paragraphs and Completed / Next / Blockers headings, with eight
preferred items. Custom provides only validated labels, headers and closed style
choices. Item preferences never authorize omitted facts.

Copy section contains its selected header and current item text. Copy All orders
Yesterday, Today and Blockers, using the current profile's headings, with one blank
line between sections. Bullets prefix each item with `- `; paragraphs join items
with LF newlines. Empty work sections display `Not specified.`; empty blockers
display `No blockers stated.`. These are view placeholders, never generated work.
Warnings, source identifiers, status, timing and edit labels do not enter copied
text. Clipboard failure reveals a selected plain-text field for manual copying.

## Editing and status

Source notes stay visible. Items have stable IDs when moved. Edits and additions
are visibly user-authored and exist only on the page; additions have no invented
source mapping. Warnings follow their target item. Regeneration protects manual
edits with an explicit replace decision. Cancel discards late results and warns
that already-sent external processing might continue. Retry is a new submission.

Fallback clearly identifies its use of conservative rules and original wording.
Uncertain classification points users to the affected source/item. Unknown work
is placed conservatively in Today with a warning; it is not presented as a
reliable time claim. Currently negated or resolved blocking must not appear as an
active blocker. Instruction-like text, markup and code are source data.

## Accessibility and visuals

Persistent labels, keyboard controls, visible focus, named copy/move actions,
polite status announcements and focused error summaries support the complete text
workflow. Text explains all states; color and the decorative orb never carry
meaning alone. The orb is progressive and can be disabled without changing results.
Reduced motion and visibility/performance guards suspend animation work.

The benchmark is fictional and model-authored. It does not constitute independent
validation or a demand study. Live provider quality and deployed timing require
separate authorized evidence.
